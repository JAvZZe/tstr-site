# robots.txt for tstr.directory
#
# Strategy, set 2026-08-19.
#
# TSTR earns nothing from a page being read. It earns when a buyer sends an
# enquiry through us and we forward it to a laboratory. So visibility is worth
# more than secrecy for anything that helps a buyer find a lab, and the things
# worth protecting are the parts a competitor could copy wholesale or that
# expose a person's details.
#
# Two audiences, deliberately treated the same for now:
#   Search crawlers (Google, Bing) send buyers who click through.
#   AI assistants (ChatGPT, Claude, Perplexity) increasingly answer
#   "who can test X to standard Y" directly. Being the cited source there is
#   worth more at this stage than withholding the content, because nobody is
#   paying us for it yet.
#
# When there is something to charge for, the levers are already in place:
# block the aggregate pages that could be scraped into a rival directory, keep
# individual profiles open, and put anything genuinely paid behind auth so
# robots.txt is not the control at all.

# ---------------------------------------------------------------------------
# All well-behaved crawlers
# ---------------------------------------------------------------------------

# Private or pointless to index

Disallow: /admin
Disallow: /api/

# Query-string variants of pages that already exist as clean URLs.
# Keeps duplicate content out of the index without hiding the content itself.
Disallow: /browse?
Disallow: /search?
Disallow: /*?page=
Disallow: /*?sort=
Disallow: /*?utm_

# AI assistants and training crawlers: allowed

# than protecting directory content that is already public. Revisit once
# listings carry registry-verified accreditations, which is the data a
# competitor cannot simply recreate.
#
# Named explicitly rather than relying on the wildcard, so the decision is
# visible and easy to reverse per crawler.
